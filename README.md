# Steal a Pet!

A Roblox pet-hatching game where the eggs are **taken, not bought**.

Wild eggs drop onto pedestals around the map. You run over, grab one, and it
welds to your back — slowing you down and painting a target on you, because
anyone can hold a prompt on *you* for three seconds and walk off with it. Get
it home to one of your three hatch pads and the real wait starts: the egg sits
there on a timer that keeps running while you are offline. When it opens you
get a pet, the pet follows you, the pet makes money, and the money buys more
eggs.

**UGC items are the top of that ladder**, earned four ways: rare egg drops,
Pet Index completion, playtime and daily streaks, and an in-game-cash shop.

---

## Running it

This is a [Rojo](https://rojo.space) project — plain `.luau` source that syncs
into Roblox Studio. There is no `.rbxl` in the repo on purpose: the map builds
itself at runtime, so an **empty baseplate is all you need**.

```bash
rokit install          # installs rojo, selene, stylua (see rokit.toml)
rojo serve             # then hit Connect in the Rojo Studio plugin
```

Or build a place file directly:

```bash
rojo build -o StealAPet.rbxlx
```

Press Play. The map, the zones, the plots, the pedestals and the props are all
generated by `MapBuilder` on the first server tick.

> **Studio setting:** the game saves to DataStores. Turn on
> *Game Settings → Security → Enable Studio Access to API Services*, or profiles
> fall back to memory and reset every run (this is handled, not fatal).

## Adding your UGC

Everything lives in **`src/shared/Config/Ugc.luau`**. It is the only file you
need to touch.

1. Publish the UGC item on Roblox.
2. Copy its catalog id — the number in `roblox.com/catalog/<ID>/name`.
3. Paste it into the entry's `assetId`.

```lua
{
    id = "skeletal_crown",
    name = "Skeletal Crown",
    description = "Hatch the Skeletal Raptor from the Extinction Egg.",
    assetId = 0,              -- <<< paste your catalog id here
    assetType = "Asset",      -- or "Bundle"
    rarity = "Secret",
    source = Ugc.Sources.HATCH,
    grantMode = "prompt",
},
```

### You can ship before the UGC exists

An entry with `assetId = 0` is a **placeholder**. It still appears in the UGC
tab, players still *unlock* it by meeting the requirement, and the unlock is
saved to their profile forever — they just see a "Coming Soon" badge instead of
a broken purchase prompt.

The moment you paste a real id in, every unlock that already happened becomes
claimable. No migration, no reset, no lost progress. That split is deliberate:

| State | Meaning |
| --- | --- |
| **Unlocked** | The player met the requirement. Saved permanently. |
| **Claimed** | The player actually took delivery of the Roblox item. |

### The four ways to earn one

Set `source` on the entry:

| `source` | Earned by | Extra fields |
| --- | --- | --- |
| `HATCH` | Hatching a specific pet | set `ugcId` on that pet in `Pets.luau` |
| `INDEX` | Pet Index completion | `world = "Forest"`, or `"All"` for the full 104 |
| `PLAYTIME` | Time played | `seconds` |
| `DAILY` | Login streak | `days` |
| `SHOP` | In-game cash | `price` |

### How delivery works

`grantMode = "prompt"` calls `MarketplaceService:PromptPurchase` — the
supported way to hand someone a UGC item you publish for free. The server
**never** marks an item claimed on the client's word: it re-checks with
`PlayerOwnsAsset` after the prompt closes.

Use `grantMode = "record"` for items you fulfil manually; the game then just
records the unlock and leaves delivery to you.

## Layout

```
src/
  shared/                 replicated to both sides
    Config/
      Pets.luau           104 indexed pets + limited event pets
      Eggs.luau           one egg per world + limited eggs, weighted pools
      Ugc.luau            >>> THE UGC REGISTRY <<<
      Worlds.luau         13 zones: income, egg cost, hatch time, unlock cost
      Rarity.luau         7 tiers: colours, income multipliers, fuse values
      Balance.luau        every tunable for carry, hatch, fuse, sell, events
    Util/                 Format, WeightedPicker, Signal, ModelFactory
    Net.luau              every remote, created server-side and named once

  server/
    World/MapBuilder      generates zones, pedestals, plots, props
    Services/
      DataService         session-locked profiles, autosave, reconcile
      CarryService        grab / steal / drop / carry  <- the core loop
      EggSpawnService     wild eggs and their luck tiers
      HatchService        hatch pads and offline-safe timers
      PetService          inventory, equipping, the income tick
      IndexService        the 0/8 and 0/104 counters, completion rewards
      UgcService          the four unlock paths + claiming
      FuseService         3-in, 1-out, 55% to tier up
      ShopService         cash eggs, Robux bundles, world unlocks
      PlaytimeService     playtime and daily streak
      WorldEventService   day/night + the luck potion drop
      StateService        client sync (heavy "full" vs light "tick")
      PropService         prompts on shop pads, sell stands, fuse, gates
      PlotService         one plot per player
      LeaderstatsService  cash + index on the player list

  client/
    UI/                   Theme, Builder, Panel, Hud, Notify,
                          PetIndexUI, ShopUI, UgcUI, PetsUI,
                          PetViewport, HatchReveal
    Controllers/          State, PetFollow, GateController, PromptController
```

## Tuning

`src/shared/Config/Balance.luau` holds every number worth arguing about:

```lua
Carry = {
    GRAB_HOLD = 0.6,          -- hold to take a loose egg
    STEAL_HOLD = 3.0,         -- hold on a PLAYER to rip it off their back
    WALKSPEED_CARRYING = 15,  -- vs 24 normally
    STEAL_IMMUNITY = 4,       -- so a pack cannot chain-strip one carrier
},
```

Worlds, eggs and pets are data too — adding a world is a row in `Worlds.luau`
plus eight names in `Pets.luau`, and the egg, the zone, the pedestals, the
index tab and the shop row all appear on their own.

### Art

Every pet and egg is a **generated blockout**, tinted by rarity, so the game is
playable before any art exists. Set `modelId` on a pet in `Pets.luau` to a
Model asset id and that model is used instead — no other code changes.

Undiscovered pets render as black silhouettes of their real model on the
rarity colour, so the shape is a hint but the identity is not.

## Controls

| Key | Action |
| --- | --- |
| `E` | Pet Index |
| `B` | Shop |
| `U` | UGC Rewards |
| `P` | Pets (equip / sell / fuse) |
| `Q` | Drop the egg you are carrying |
| `Esc` | Close the open panel |

Everything else is a proximity prompt: hold on an egg to take it, hold on a
player to steal theirs, hold on your pad to place or open.

## Things wired but waiting on you

- **`Ugc.luau` asset ids** — all `0`. See *Adding your UGC* above.
- **`ShopService.PRODUCTS`** — Developer Product ids for the Robux egg bundles.
  Until filled, those buttons say the bundle is not live rather than failing.
- **`Eggs.luau → durationSeconds`** on the Extinction Egg counts down from
  server start. Swap for a fixed unix timestamp once you know your launch time.
